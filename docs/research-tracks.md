# Research Tracks

## Hunter simulation centralization

- Define the minimum hunter build schema needed to index simulation results.
- Store objective tags, profile brackets, and confidence metadata alongside each result.
- Use retrieved simulations as optimizer seeds instead of brute-forcing the full solution space first.

## Mech planner feasibility

- Identify all required inputs and progression assumptions in the current planner.
- Capture time-to-max formulas and hidden constraints before rewriting UX.
- Decide whether the first rebuild should be estimator-only or recommendation-capable.

## Input automation

- Rank profile fields by user pain and automation payoff.
- Support paste/import first because it has the best implementation-to-impact ratio.
- Reserve screenshot parsing for the highest-friction workflows once profile and data schemas stabilize.
