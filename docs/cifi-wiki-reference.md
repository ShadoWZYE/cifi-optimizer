- The Zeus
- The Ouroboros

The ships page describes shared ship concepts as:

- Rank
- Installs
- Crew
- Evolution

The ships page also notes that community terminology exists for install codes and install ordering.

User-confirmed loadout behavior to preserve in the rebuild:

- 3 player loadouts can exist at once
- loadouts are swapped between LRs
- every loadout spans all ships
- installs are assigned in order, one point at a time at the start
- automation respects that install order later
- install availability is progression-gated
- meltdown becomes a critical modifier post-Ouroboros / first traversal

## Loop prestige notes

The Loop Prestige page says loop prestige:

- unlocks after purchasing The Zagreus,
- resets many resources and progression layers,
- rewards Mod Points,
- and increases loop requirements over time as resets increase.

These details matter for LR-aware tooling and snapshot design.
