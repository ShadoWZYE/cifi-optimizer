# MVP Direction — CiFi Optimizer

## Core Idea

A unified tool that tells the player:

"What should I do next, and why?"

---

## Input

* Manual / guided player profile
* No heavy import required

---

## Output

A ranked list of actions:

* best upgrades
* best focus areas
* warnings
* tradeoffs

Each with:

* why now
* cost
* ETA
* confidence

---

## MVP Modules

1. Shards

   * milestone optimization
   * threshold awareness

2. Spend

   * diamond/token planning
   * best-next-buy

3. Loop Guardrails

   * reset timing warnings
   * inefficiency detection

---

## Non-MVP

* OCR
* full automation
* late-game optimization
* generic tables

---

## UX Principle

Replace:

* spreadsheets
* Discord advice
* fragmented tools

With:
→ one clear recommendation feed

---

## Philosophy

Clarity > perfection
Trust > complexity
Guidance > simulation
