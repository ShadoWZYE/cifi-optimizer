# CIFI Reference Notes

This file is a lightweight naming and system anchor list for the repository.

Use it as a practical glossary, not as a substitute for the verified spec.

Primary grounding document:
- `docs/cifi_verified_spec.md`

---

## Naming rule

Use **CIFI** consistently in docs and safe user-facing copy.

Avoid:
- CiFi
- Cifi

Use:
- CIFI

---

## Core system anchors

These are the kinds of real system names the repo should prefer when describing player state or mechanics:

- CIFI
- Shards
- Shard Mining Menu
- Operations
- Shard Milestones
- Loop Prestige
- Diamonds
- Mod Points
- Hunters
- Trait Spheres
- Academy Relics
- Ouroboros systems

---

## Usage rule

If a term is not clearly tied to a real CIFI system, do not casually introduce it into canonical player state.

Instead:
- document it
- label it
- move it into research or experimental notes
- or leave it out of the grounded schema

---

## Reference categories

### Verified gameplay terms
Use in canonical game-state docs and schema work when externally grounded.

### Community-tool terms
Allowed when integrating helper models, but must be labeled clearly.

### Repo-only placeholders
Do not present as game truth.
