## Source usage policy

Use sources in this priority order:

1. official developer/public listings or posts
2. strong community wiki references
3. named community tools / sheets
4. repo assumptions last

If sources conflict:
- prefer official sources
- otherwise mark the issue as unresolved
- do not invent a mechanic to fill the gap

---

## Confidence categories

### High confidence
- public naming anchors
- real shard system existence
- real operations relationship
- real reset relationship with Loop Prestige

### Medium confidence
- some detailed threshold/cap specifics from community sources

### Low confidence
- exact formulas not directly documented in public sources
- any mechanic currently only implied by repo code
- any placeholder values currently stored in repo data

## Repo use guidance

Every future data table or formula should be accompanied by:
- source label
- source URL if public
- import date
- confidence note
- whether it is verified, community-tool, or derived
