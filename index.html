Player Data

Shared profile and labeled helpers

Shared PlayerProfile truth is limited to grounded CIFI account state. The active form only shows values a typical player can quickly provide from the game without derivation or manual rollups; aggregated or derived values stay out of this manual flow. Planner-only helpers stay labeled, and ship calibration remains outside shared profile truth as external-model implementation data.

Manual profile inputs should come from values a typical player can quickly read in game. Accepted number formats: 5800, 5.8k, 9.8t, 7.15e549.

Planner-only helper inputs are optional. Only helpers a typical player can still read quickly in game belong here; derived rates such as shard income per hour stay out of the active form.
